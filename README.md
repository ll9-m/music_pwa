# 本地音乐播放器（离线 PWA）

一个**完全离线**的浏览器音乐播放器：扫描你电脑里的音乐文件夹，在浏览器里播放。没有登录、没有流媒体、没有任何联网功能——所有数据（索引、封面、播放列表、播放进度）都保存在本机浏览器里。

## 启动
直接浏览器访问：https://ll9-m.github.io/music_pwa/

```bash
node server.js        # 默认 http://localhost:8080
# 或指定端口：node server.js 9000
```

然后用 Chrome / Edge 打开 <http://localhost:8080>。

> 必须通过 `localhost` 或 HTTPS 访问——这是浏览器的要求（Service Worker、离线缓存、文件夹授权都需要安全上下文）。

## 首次使用

1. 打开应用 → 点「**选择音乐文件夹**」（或在 **设置 → 音乐文件夹** 中选择）。
2. 浏览器会弹出系统文件夹选择框，选中你的音乐目录并授权。
3. 应用会递归扫描文件夹，读取歌曲标签（标题 / 歌手 / 专辑 / 封面 / 时长）。
   - Chrome / Edge 会**记住**这个文件夹：以后每次打开自动扫描，新歌自动入库。
   - 如果浏览器重启后提示「需要重新连接」，点一下授权按钮即可。
   - Firefox / Safari 不支持文件夹记忆，会退化为每次访问手动选择一次文件夹（功能不受影响）。

> 说明：出于浏览器安全模型，网页**无法**让你直接输入一个磁盘路径（例如 `D:\Music`）来访问文件，只能通过系统文件夹选择框授权。授权一次后即等同于"设置了文件夹路径"。

4. 建议点击地址栏的「安装」图标（或 **设置 → 安装应用**），把它装成桌面应用，窗口独立、支持媒体键与系统媒体控制。

## 功能

- **媒体库**：歌曲 / 专辑 / 歌手 分组浏览，全局搜索，多种排序
- **播放**：播放队列、随机播放、列表循环 / 单曲循环、快进快退、音量、播放计数与最近播放
- **正在播放**：大封面 + 主色氛围光、频谱动画、队列抽屉（可拖拽排序、点选跳转、移除）
- **歌词**：自动读取与歌曲同名的 `.lrc` 文件，逐行高亮 + 自动滚动，点击歌词行跳转
- **播放列表**：新建 / 重命名 / 删除，收藏（喜欢）与最近播放智能列表
- **均衡器**：5 段 EQ（60Hz – 14kHz），带预设
- **快捷键**：空格播放暂停、`←→` 快退快进、`↑↓` 音量、`P/N` 上下首、`M` 静音、`S` 随机、`R` 循环、`L` 喜欢、`F` 正在播放全屏、`/` 搜索
- **主题**：浅色 / 深色 / 液态玻璃（毛玻璃 + 动态色斑背景）
- **完全离线**：Service Worker 预缓存全部资源，断网可用；媒体键 / 锁屏控制（Media Session）

## 支持的格式

MP3（含 ID3v1 / v2.2 / v2.3 / v2.4）、FLAC、M4A / AAC（MP4）、OGG（Vorbis / Opus）、WAV、WebM。
标签支持内嵌封面、GBK 中文编码兼容。WMA / APE 等浏览器不支持的格式不会入库。

## 技术说明

- 纯原生 HTML / CSS / JS（ES Modules），**零依赖、无构建步骤**
- 文件访问：File System Access API（句柄持久化到 IndexedDB），降级方案为 `webkitdirectory` 文件选择
- 元数据解析为手写实现（`js/metadata.js`），按需切片读取文件，不整文件载入内存
- 封面按专辑懒提取，缩略图（WebP 256px）缓存在 IndexedDB
- `node server.js` 只是一个静态服务器（支持 Range），你也可以用任何静态服务器代替
